AQ consumers must preserve these contracts:

- API major 1 uses `/v1` and `X-AQ-Graph-API-Version: 1`; unsupported header versions return `400 unsupported_api_version`. Schema 8 readiness verifies exact embedded migration versions/checksums. Do not assume an older image can read a newer schema.
- Mutations use opaque positive CAS version/revision tokens. Stale versions return `409 conflict` and do not overwrite. Batches are atomic and bounded to 100 operations.
- Receipts are scoped by authenticated actor, workspace and operation. The same key with the same parsed payload returns the original committed outcome and IDs; a changed payload returns 409. Timeouts may follow commit, so retry the original key/payload. Pilot receipt/history retention is indefinite, with no automated pruning.
- Credentials authorize a workspace actor with read/write/admin capability. Caller-supplied actor fields are rejected. AQ task/session provenance attributes work to the authenticated principal; it does not impersonate another actor or create finer AQ attempt authority. That authority belongs to AQ's adapter.
- Admin routes issue/rotate/revoke credentials and protect the last administrator. Remove bootstrap settings before rotating the original bootstrap identity. Keep a stable actor identity when reconciling actor-scoped receipts across token rotation, and retain an independent administrative recovery route.

The optional native CLI was built against glibc 2.39; the selected container supplies its Debian runtime.
